# Настройка триггерных email-цепочек (Unisender)

Две цепочки писем, которые запускаются после кнопок в блоке «Получить презентацию»:

| Кнопка на сайте | Сегмент (код) | Папка с письмами | Список в Unisender |
|---|---|---|---|
| Шоколадные конфеты (отели) | `chocolate` | `emails/chokolade/` | «KUTKEVICH — Конфеты» |
| Цукаты и мармелад (ритейл) | `marmelad` | `emails/marmelad/` | «KUTKEVICH — Цукаты и мармелад» |

Логика тайминга писем (письмо 1 → пауза → письмо 2 → пауза → письмо 3) живёт **внутри
Unisender** (раздел «Автоматизация»). Сайт и наш Cloudflare Worker делают только одно:
кладут email в нужный список. Дальше Unisender сам шлёт цепочку.

```
Кнопка на сайте → мини-форма (email) → Worker → Unisender API (subscribe в список A или B)
                                                          │
                                          Автоматизация Unisender:
                                          письмо 1 (сразу) → +2 дня → письмо 2 → +3 дня → письмо 3
```

---

## Что делает разработчик (уже готово в коде)

- Кнопки презентации открывают мини-форму (email + согласия) — `index.html`.
- Worker принимает заявку и подписывает email в нужный список — `worker.js`.
- Письма приведены к виду под Unisender (merge-теги `{{Name}}`, `{{UnsubscribeUrl}}`).

**Осталось вставить в Worker секреты** (см. шаг 5) — это сделаю я, как только пришлёте ключ и ID списков.

## Что нужно сделать (один раз, ~30–40 мин)

### Шаг 0. Выложить папку `emails/` на сайт (иначе картинки не загрузятся)

Фото в письмах ссылаются на `https://kutkevich.ru/emails/...`. Чтобы они открывались,
папку `emails/` нужно закоммитить и запушить в репозиторий сайта (GitHub Pages):

```
git add emails/
git commit -m "Add email templates and images"
git push
```

Проверка: после деплоя в браузере должна открыться картинка
`https://kutkevich.ru/emails/chokolade/photo-letter-1.jpg`.

### Шаг 1. Подтвердить домен-отправителя (САМОЕ ВАЖНОЕ для «не в спам»)

Письма цепочки уходят с адреса **`sales@kutkevich.org`** (на него же ведут ссылки
«ответьте на письмо» в письмах). Значит в Unisender нужно подтвердить домен **`kutkevich.org`**.

1. Unisender → **Настройки → Отправители** → добавить адрес `sales@kutkevich.org`.
2. Unisender покажет DNS-записи (**SPF**, **DKIM**, обычно и **DMARC**).
3. Эти записи нужно добавить в DNS домена `kutkevich.org` (там, где он зарегистрирован).
   - Если доступа к DNS `kutkevich.org` нет — напишите мне, помогу.
4. Дождаться галочки «домен подтверждён» (DNS обновляется от 15 мин до нескольких часов).

> Без подтверждённого домена письма массово падают в спам. Это шаг №1, не пропускать.

### Шаг 2. Создать два списка

Unisender → **Контакты → Списки** → создать:
- `KUTKEVICH — Конфеты`
- `KUTKEVICH — Цукаты и мармелад`

Запишите **ID каждого списка** (число, видно в адресе или настройках списка) — отдадите мне.

### Шаг 3. Загрузить письма (по 3 в каждую цепочку)

Для каждого письма: Unisender → **Письма → Создать → "Свой HTML"** → вставить
содержимое файла:

**Цепочка «Конфеты»** (`emails/chokolade/`):
- Письмо 1 — `letter-1.html` (или `letter-1-v2.html` — выберите вариант)
- Письмо 2 — `letter-2.html`
- Письмо 3 — `letter-3.html`

**Цепочка «Цукаты и мармелад»** (`emails/marmelad/`):
- Письмо 1 — `letter-1.html`
- Письмо 2 — `letter-2.html`
- Письмо 3 — `letter-3.html`

> Файлы `*-print.html` — для печати/PDF, в рассылку их не грузим.

**Картинки.** В цепочке «Конфеты» фото уже прописаны абсолютными ссылками на
`https://kutkevich.ru/emails/...` — грузить их в Unisender вручную НЕ нужно.
Единственное условие: папка `emails/` должна быть выложена на сайт (см. шаг 0).
Цепочка «Цукаты и мармелад» — фото в работе.

### Шаг 4. Собрать автоматизацию (цепочку) для каждого списка

Unisender → **Автоматизация** → создать сценарий:
- **Старт:** «Контакт добавлен в список» → выбрать нужный список.
- **Блок 1:** отправить Письмо 1.
- **Пауза:** 2 дня (рекомендация, настраивается).
- **Блок 2:** отправить Письмо 2.
- **Пауза:** 3 дня.
- **Блок 3:** отправить Письмо 3.
- Включить сценарий.

Повторить для второго списка со своими письмами.

> Если в вашем тарифе нет «Автоматизации» — у многих тарифов есть упрощённая
> **«Серия писем»**, привязанная к списку: тот же эффект. Если нет ни того, ни
> другого — напишите мне, сделаю тайминг на стороне Cloudflare (запасной вариант).

### Шаг 5. Дать разработчику доступ к API

1. Unisender → **Интеграция и API → API-ключ** → скопировать ключ.
2. Прислать мне: **API-ключ** + **ID двух списков** (из шага 2).
3. Я вставлю их в Worker как секреты:
   - `UNISENDER_API_KEY`
   - `UNISENDER_LIST_CHOCOLATE`
   - `UNISENDER_LIST_MARMELAD`

### Шаг 6. Тест

1. Открыть сайт → кнопка «Шоколадные конфеты» → ввести свой email → отправить.
2. Проверить: контакт появился в списке «Конфеты», пришло Письмо 1.
3. То же для кнопки «Цукаты и мармелад».
4. Проверить, что письмо приходит во «Входящие», а не в «Спам» (Gmail, Mail.ru, Яндекс).

## Опция: с подтверждением подписки или без

В Worker параметр `UNISENDER_DOUBLE_OPTIN`:
- **`4`** (по умолчанию) — подписываем сразу, презентация уходит моментально.
  Человек уже дал согласие галочкой на сайте — это допустимо.
- **`3`** — Unisender сначала пришлёт письмо «подтвердите подписку», цепочка
  стартует только после клика. Надёжнее для репутации, но презентация приходит
  не сразу (часть людей не подтвердит). Можно переключить позже.
